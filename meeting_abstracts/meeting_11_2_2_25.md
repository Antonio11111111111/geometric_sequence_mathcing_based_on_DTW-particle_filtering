#### 示例：如何在Markdown中编写代码和LaTeX公式

1. **代码书写**：
   在Markdown中，可以使用反引号（`）来插入代码块。

   * 单行代码使用单个反引号包裹：

     ```markdown
     `print("Hello, World!")`
     ```

     显示效果：
     `print("Hello, World!")`

   * 多行代码可以用三个反引号包裹：

     ````markdown
     ```python
     print("Hello, World!")
     ````

     ````

     显示效果：
     ```python
     print("Hello, World!")
     ````

2. **LaTeX公式书写**：
   可以使用美元符号 `$` 来插入公式，适合书写数学公式。

   * 内联公式：
     在Markdown文件中，将公式包围在单个 `$` 中：

     ```markdown
     $ \alpha + \beta = \int_{x}^{y} \gamma d\gamma $
     ```

     显示效果：
     $ \alpha + \beta = \int_{x}^{y} \gamma d\gamma $

   * 块级公式：
     用两个美元符号 `$$` 包围公式，用于显示更复杂的数学表达式。

     ```markdown
     $$ x_1 + x_2 + \dots + x_n = \Sigma_{k=1}^n x_k $$
     ```

     显示效果：
     $$
     x_1 + x_2 + \dots + x_n = \Sigma_{k=1}^n x_k
     $$
